# Changelog

## [4.0.3] - 2026-11-28

### Added

- 创作中心支持普通本地文件附件、工具分组短帮助及五份按需读取的内置 Skill。

### Changed

- 连续输入复用同轮次队列，工具结果展示、卡片样式和上下文顶部布局更清晰。

### Fixed

- 内嵌 FFmpeg 帮助自动返回真实正文，并正确提供 argv 空终止项。
- macOS 视频首显的画面层与控件尺寸同步；快速全屏转场仍保留未定因回归边界。

正式交付说明见 [4.0.3](releases/4.0.3.md)，完整桌面记录见 [desktop changelog](../MaiChat/desktop/CHANGELOG.md)。

## 3.0.1 — 2026-11-17

### Added

- Windows 电脑操作支持持续按住后截图观察、继续移动再明确释放；细操作可按任务组合。
- Windows 系统触摸支持最多十点，笔输入支持悬停、压力、倾斜和橡皮操作。
- 创作中心交付 PDF/Markdown 文件时显示真实内容首屏缩略图，点击继续预览原文件。

### Changed

- Windows 输入统一使用项目现有的系统 API 执行核心；25 个模型 action 保持独立的提效接口设计。
- 桌面“我的”和“设置”分为独立页面，侧栏图标统一品牌蓝，用空心/实心区分选择状态。
- 工具欢迎说明合并截屏与电脑操作，去除基础问答卡，继续按实际模型/工具可用性过滤入口。
- 图片预览支持 Windows 滚轮及 Mac 缩放手势，放大后可平移、双击恢复适应窗口。

### Fixed

- 补全最小化、无标题、小尺寸和浮动窗口发现，移除窗口列表的静默 200 项截断。
- 规范原始键身份、修饰键映射、重复和释放状态，保留取消、失败重试及外部持有保护。
- 修正触摸方向换算；区分笔的结束接触与离开感应范围。
- 修正文件缩略图加载首帧压缩布局、UTF-8 截断尾部处理和完成 future 持有整页 PDF 内存的问题。
- 改进视频首次打开时控制条与画面的对齐，以及图片关闭回源动画的连续性。
- 补齐 SoundTouch 发布源码中的空配置头，修复干净 macOS 构建遗漏输入文件的问题。

### Release boundaries

- 本次 GitHub 资产为 Windows x64 与 Mac arm64。移动端版本不随此 Desktop 版本号变更。
- 虚拟设备、手柄及控制器反馈不在当前能力范围；不宣称与固定 Sunshine 后端逐事件严格相同。
- 新输入的实际接收验证来自 Windows 自有测试窗口；不扩展为所有应用或 Mac 全局输入均已验收。
- Mac 包使用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；Windows 签名状态以平台 manifest 为准。
