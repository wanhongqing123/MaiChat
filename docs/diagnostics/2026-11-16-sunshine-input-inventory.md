## 1. Protocol envelope, supported packets, serialization

The common packed envelope is `uint32 size` big-endian **excluding the size field**, then `uint32 magic` little-endian. `netfloat` is a 4-byte little-endian float. S accepts the modern packet set below; merely finding an older structure in M is not evidence that S dispatches it. Sources: [M `src/Input.h`:5–14](https://github.com/moonlight-stream/moonlight-common-c/blob/94c65fd364d17b223f00a8763c9a5d94a66cb8dd/src/Input.h#L5), [S `src/input.cpp`:1790–1839](https://github.com/SunshineStream/Sunshine/blob/bb6930bd782ed3edd2eea9a71d46b42183be9358/src/input.cpp#L1790), [S `src/input.cpp`:2208–2253](https://github.com/SunshineStream/Sunshine/blob/bb6930bd782ed3edd2eea9a71d46b42183be9358/src/input.cpp#L2208).
