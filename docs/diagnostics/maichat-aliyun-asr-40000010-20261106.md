# 阿里云语音识别 40000010

2026-11-06 02:01，用户 iOS 199 截图：IM 按住转文字失败，提示
“语音转文字失败，未发送：阿里云语音识别失败（40000010）”。

阿里云官方把该码定义为 `Gateway:FREE_TRIAL_EXPIRED`，服务试用权限不可用：试用结束、
对应服务未开通商用版，或账号欠费。不是 Token 过期错误码；不能靠重录、刷新 Token 或
扩大超时来修复。具体账号的服务状态及余额尚未查询，不能直接断言已经欠费。

官方依据：https://help.aliyun.com/zh/isi/support/error-codes/ 及
https://help.aliyun.com/zh/isi/getting-started/examples-of-using-sdks-and-managing-restful-apis 。
服务端目前只签发 NLS Token，客户端 SDK 直连 NLS；Token 签发成功不代表语音产品的
试用/商用权限可用。初查时未替用户开通计费服务或发起付费 ASR 验收；用户随后要求
充值后重试，结果见下文。

客户端两处原来只拼接错误数字：`AliyunSpeechTranscript.apply` 的 JSON 状态和
`AliyunSpeechEngine.onNuiEventCallback` 的 SDK retCode。现共用具体中文说明，指向服务
开通状态及余额检查。未知错误码继续保留原数字；录音、识别、未发送边界和偏好不变。
这部分代码只改善可操作的报错，不负责恢复阿里云服务。后续需核对实际 NLS 项目的
实时语音识别商用开通状态/余额，用户也可在“我的 → 偏好设置 → 语音识别服务”选择
已有腾讯云通道。
