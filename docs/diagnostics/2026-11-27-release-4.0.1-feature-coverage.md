## 升级与数据边界

正式目录位于 Qt AppLocalDataLocation 下 `Agent/Accounts/<账户 SHA256>/`。`sessions/YYYY/MM/DD/` 的 rollout 和 `sessions/.journal/` 是权威记录，`agent.db` 是索引。备份要复制整个账户 Agent 目录；至少必须包含完整 `sessions/`，不能只复制数据库。保留迁移前旧库与 sidecar，不让新旧程序并发写同一账户。源损坏时保留现场并明确失败，不通过重建空历史继续模型或工具。

历史工具名称保留用于展示；正式入口为 `exec_command` / `write_stdin`、`apply_patch`、`computer` 与高级 `computer_input`。独立 `file_*` 不再注册给桌面和移动模型，`desktop_browser` 与专用 CDP 构建删除。工具按需发现基于既有普通核心，不引入 MCP，也不引入独立 Agent 服务进程。
