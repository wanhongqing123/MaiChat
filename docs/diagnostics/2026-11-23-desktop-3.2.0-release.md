## 复现与预期

- 其他设备发入新输入或上一轮退役后接续排队输入，所属会话应在首个模型 token 前显示等待状态与停止按钮，保留草稿。
- 远程输入框收到自有图片 MIME 或本地文件拖放后应实际形成可发送附件；仅图片可发，草稿重开保留，清除不复现，遵守既有附件限制。
- Chat/Responses 明确 HTTP 413 时，应按实际 JSON 编码字节恢复；最多四次严格缩小的恢复，保留原史和当前受保护输入，不重跑工具或降低输出额度。摘要请求也有界重新分块；无法安全缩减时明确停止。
