# 移动端创作中心工具与正文顺序

2026-11-05；main / eee43402 和既有未提交工作区。

## 操作与预期

同一条助手回复先输出引言，调用 A1/A2 工具，输出 A 段说明，再调用 B1 工具，
输出 B 段说明，最后调用 C1/C2 并输出 C 段说明。移动端应保持这一片段顺序，
只将相邻工具合成各自的折叠组，组内统计不得跨正文合并。流式新增 B/C 时，
A 组位置和展开状态不变；各组可独立展开，历史加载、切换会话后顺序保持一致。
不展示思考正文，不重新执行工具，不改源消息或跨设备协议。

用户明确本项先处理 iOS，并核对 Android；桌面显示逻辑不在本次修改范围。

## 定位

iOS `AIMessageRow` 用 `message.parts.filter(kind == tool)` 收集整条消息工具，
在遍历文字前显示一个汇总块；后续工具因此被移到先前文字上方。Android
`MessageRow.bind` 仅持有一个 `toolDetails` 容器，遇到后续工具仍往第一次创建的
容器追加，跨过中间正文。两者均是展示层聚合问题。
