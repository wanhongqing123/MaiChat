# 云盘原件下载工具

2026-11-06；main / eee43402 工作区。用户排查 Mac 视频颜色时指出，Agent 应能直接取得
云盘里的原文件，并授权在缺少入口时新增下载工具。原有浏览/打开媒体工具不返回视频
文件路径，Session 附件下载仅适用于已分享给指定 Session 的独立空间，不能代替云盘下载。

预期操作：列出当前账号云盘文件，调用 `maichat_cloud_drive_download_media`，提供
`media_id` 及工作区内的新 `output_path`。完成后返回可交给本地媒体分析工具的原件路径，
不打开播放器。失败、取消、无权访问或同名文件时不得产生半个目标文件或覆盖原文件。

普通能力与工具入口复用 `MAI_CLOUD_DRIVE_DOWNLOAD_MEDIA`：C++ 内核自己获得短期读取链接，
直连存储下载，并在原子交付前核对完整字节数。复用原有代理、TLS、重定向和取消处理。
本地路径不发给账号服务；令牌和签名 URL 不进入模型结果。iOS、Android、Desktop 只负责
工作区路径、账号生命周期和调用适配。云端仍只有账号/配置控制面，未增加媒体转发。

QA 与源码快照：`/private/tmp/maichat-cloud-download-20261106/`。

验证结果：

- 共享 C++ 的本地 HTTPS 下载及云盘集成测试 2/2 通过（41.31 秒）。检查原件字节数及
  内容一致、同名文件保持原内容、无权限拒绝、完整交付前的尺寸核对；保留已有取消、
  TLS 和重定向回归。测试仅使用临时证书和合成媒体。
- Desktop 工具契约及真实宿主 HTTPS 集成 2/2 通过（7.00 秒）。注册入口共 16 个，
  视频及 PNG 原件都逐字节一致，下载不会打开媒体窗口；越界、同名路径被拒绝。
- iOS 模拟器 build-for-testing 和 Android assembleDebug/assembleDebugAndroidTest 编译通过。
  这两项只验证当时的跨端适配编译，未安装新手机版本，也未做手机端下载的实际操作验收。

账号数据及签名 URL 未写入测试产物。没有以线上账号下载另一个用户的文件。
Mac 当前运行的 2.2.34 尚不含此入口；它随待交付的新构建生效，不能把源码测试通过
等同于用户正在运行的旧版已经可用。
