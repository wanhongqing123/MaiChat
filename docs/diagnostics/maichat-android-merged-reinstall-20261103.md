## 构建环境定位

最初原生构建止于Windows找不到bash。现有工具无需另行安装：MSYS2在 `E:/OpenSource/msys64`，Meson1.12.1在用户Python314 Scripts，VS18提供host x64链接环境。仅对本次构建进程载入VS环境、设置 `MSYSTEM=MINGW64` 与 `MSYS2_PATH_TYPE=inherit` 并补PATH；保留MSVC link在MSYS同名工具之前。

后续明确错误依次为Meson未找到、Android prefix `/` 被MSYS转换成Windows盘路径、Ninja自动探测失败。按错误修正进程环境：加入实际Meson路径、`MSYS2_ARG_CONV_EXCL=--prefix=`、`NINJA`固定Android SDK CMake所带的绝对路径。未跳过FFmpeg目标或以旧App/JNI替代新源码。正常增量构建会复用未变化的第三方对象，不宣称全部第三方从零重编。

新版人像模型初始缺失，使用仓库下载器按固定revision取得四份模型，4/4 SHA-256核验通过。模型不入Git，APK内四份模型与已核验源码资源逐字节哈希一致。
