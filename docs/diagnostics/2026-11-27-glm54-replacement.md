# GLM-5.3 旗舰直接升级 GLM-5.4

## 要求与依据

用户指定 https://docs.bigmodel.cn/cn/guide/models/glm-5.4 ，要求将旗舰5.3直接换为5.4；
说明普通API尚待开放后，用户明确回复“直接替换，我的账号已支持5.4”。据此不保留旗舰5.3
作为可选或可执行型号；glm-5.3-flash是独立型号，保持不变，不改其他模型选择或通用GLM凭据。

官方模型页注明视觉输入、1M窗口、128K最大输出。沿用项目GLM对应已核数字口径
1048576/131072，Responses基址仍为 https://open.bigmodel.cn/api/v1 。
API端点/协议说明参考 https://docs.bigmodel.cn/cn/guide/develop/responses/introduction 。
未切到Chat协议或Coding Plan独立协议，没有模型代理，也没有新增密钥存储入口。

## 修改与预期操作

桌面、Android、iOS选择菜单及路由均使用精确glm-5.4；影像工具使用共享能力判断，
不再把5.4视为旧旗舰的纯文本型号。菜单原有Flash和其他供应商保留。
设置读取仅精确映射旧glm-5.3→glm-5.4，不做字符串前缀替换；本地模型来源和其他设置保留。

Core启动在工作线程开始前，以正式存储追加型号元数据更新；写入错误明确失败。
即使当前只有DeepSeek/OpenAI路由，归档的旧GLM会话也能恢复，不为迁移读GLM密钥或发送请求。
正常显式UpdateSession仍严格校验路由。原始消息、旧供应商response item和usage记录不改写；
模型身份变化使旧计量采样、旧加密续接不能被5.4请求冒用。
