# MaiChat 2.2.55 桌面候选包

日期：2026-11-10。交付范围：Windows x64 EXE/ZIP、macOS Apple Silicon DMG/ZIP。
本文件记录候选变更；最终源码、包大小、SHA256 和实际传输回执以交付 manifest 为准。

## Added

- 电脑操作工具支持观察整个显示器并通过同一核心接口发送键盘、指针和拖动操作，继续复用常驻采集。
- 新增普通历史读取 API 和 `session_history` 工具，可分页查回原消息、工具输出、链接和媒体来源。
- 桌面所属端可将新会话图片发布为临时 OSS 引用，远程桌面会话据此下载预览；临时图片服务已实际部署。

## Changed

- 长上下文使用已知模型容量和明确标注的 token 估计触发增量摘要，检查点落库后复用；原始历史继续保留。
- 保留当前用户输入、未覆盖的近期原文和原始图片。连续大工具组可成对摘要，图片仍进入模型视觉输入并携带真实来源范围。
- 未知模型容量保留完整原文或有效检查点，不虚构统一窗口。真实模型的摘要质量和耗时仍须另行验收。

## Fixed

- 媒体导入等待卡增加取消与超时恢复，保留输入草稿，避免一次卡住长期阻断后续发送。
- 修正 Windows 内置 curl 的系统信任库配置，并向远程会话提供可诊断的失败信息。
- 移除 Windows 关闭按钮的红色 hover 高亮。
- 修正活动轮次压缩、追加截图后的检查点复用、无正文分隔的大批工具结果，以及空历史超长指令的边界。
- 原史读取明确处理非法 UTF-8 原字节进展和 Base64 表示，避免错误报告已到结尾。

## 验收和使用边界

Windows 已实际完成独立编辑器的另存为、读磁盘、清空和重新打开，以及独立 Chrome 的原生
地址栏导航、同一会话 Cookie 和正文核对。它们证明原生执行链可工作；实际视觉模型自主完成
任务仍需单独验收，不能由固定步骤或 Fake 模型测试替代。

临时图片过期后不重新上传。已有完整本地缓存可继续查看，未缓存的过期图片显示已过期。
旧历史不自动补传；iOS 接收代码已在源码中，本次桌面候选不会更新手机，iOS 所属端首次发布仍未接入。
后台此次上线源为 `8cde6a87418c84691598b567f49a68255880bd10`，客户端后续修正没有再次改动线上服务。

本轮以新目录保存候选与校验文件，保留旧包及现装应用。Windows 安装包未签名；Mac 使用
ad-hoc 签名且未公证。实际 Mac 构建和运行环境为 Apple Silicon/macOS 27.2，没有据此冒称在
其它 macOS 版本完成运行验收。两端包内实际启动、依赖与原始字节一致性由出包门禁分别记录。
