# MaiChat 4.0.3

2026-11-28 · Windows x64 / macOS arm64

本版改进创作中心的连续输入、文件附件和工具帮助，包含 macOS 视频首显尺寸修复。
Windows 与 Mac 安装包使用同一冻结源码；4.0.2 的 tag 和附件继续保留。

## 创作中心

- 运行任务时继续发送的消息按同一轮次接收和排队，用于补充或调整当前任务。
- 输入框支持拖入本地文件，并与“选择文件”共用附件草稿；图像、视频保留原有处理路径。普通文件传递路径引用，拖入不会自动发送或上传，也不会移动、删除原文件。
- 工具执行详情显示可读的命令输出，保留原始结果；卡片改用浅蓝详情、薄边框、圆角和状态标签。
- 顶部上下文进度与文字整组居中，更多菜单保持在右侧。

## 工具与内置指南

- FFmpeg 的 `-h`、滤镜/编码器主题和能力列表会自动把真实正文交给模型，不再只返回空的成功结果。长帮助保留有界前缀并明确标记截断。
- 增加按当前平台和模型可用性生成的分组简要帮助。复杂用法可按需读取随各端核心内置的五份 Skill，不改写用户自己的技能目录。
- 精简常驻能力摘要与工具描述，详细参数仍按需发现。小上下文模型可能在多步调用中触发明确的容量限制，不能把首请求可发送当成整个工具循环都能容纳。

## macOS 视频

修复准备播放后第一次显示时，实际视频层仍停留在旧尺寸、画面与标题/底部控件分离的问题；本地与自有云盘入口的 SDR/HDR 首显、窗口尺寸变化已有定点验证。

## 升级与交付

继续使用 4.0.2 的当前会话存储；已有新版记录不会因本次升级再次清空，也不自动导入旧 SQLite 历史。账号、IM、云盘及模型配置保持现有升级路径。

三端源码版本为 4.0.3（Android 288 / iOS 237）。本次 GitHub 附件为 Windows ZIP/Setup 与 macOS arm64 DMG/ZIP，各附 manifest 和 SHA256SUMS；不提供 Android 或 iOS 的公开安装包。iOS 真机更新另按用户授权执行，其结果在交付记录中核对。

## 已知边界

- 保留一次 macOS HDR 快速连续全屏切换回归的未定因失败；本次首显修复和其他通过记录不代表所有全屏转场均已验收。
- Windows 签名和安装器验证范围、macOS 签名/公证及最低系统版本，以本次正式平台 manifest 为准。旧系统与 Intel 不因构建检查而被宣称已经实机验证。
- 本轮不重新部署后台或调用付费模型/媒体供应商，不宣称修复此前独立记录的所有网络链路问题。

正式附件的源码提交、摘要及实际启动验证会在发布时随清单提供。
