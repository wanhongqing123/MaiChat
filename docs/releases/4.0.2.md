# MaiChat 4.0.2

2026-11-28 · Windows x64 / macOS arm64

本版让使用旧 SQLite 会话存储的账户直接从空的新版 Agent session 开始，落实“不导入旧历史”的选择，并提供已完成后台配置的 GPT-6.1 Sol 接入。保留 [4.0.1](https://github.com/wanhongqing123/MaiChat/releases/tag/v4.0.1) 的全部功能，新版本独立出包。

## 会话存储

- 常规启动不导入旧 SQLite 会话，也不恢复旧库的未完成迁移。旧文件及其 sidecar 原地保留，无需手动转换或清理数据库。
- 新会话使用独立的 SQLite 索引与追加 JSONL 原文；本地旧库即使仍有连接，也不作为新会话的数据来源。
- 已有有效新版 JSONL 存储继续使用；之后创建的会话能够重开恢复，删除索引后可从自己的权威日志重建，不会每次启动清空记录。
- 定时任务使用新版会话对应的独立索引，不从旧会话继续执行任务。当前存储损坏或版本不支持时明确报错。
- 本次只调整 Agent session。账号登录、IM 消息、云盘文件、模型配置及其他产品数据不重置。

## GPT-6.1 Sol

- 客户端接入与后台 Key 配置均已完成，沿用登录后账号下发凭据、客户端直连 OpenAI 的方式，无需手工填写 Key。
- 创作中心可选择 GPT-6.1 Sol，支持图像输入和 low、medium、high、xhigh、max 五档思考强度。
- 实际后台受保护接口与账号解析模块均验证 OpenAI 字段有效；正式源码的 C++ 客户端已通过两次有界真实请求及一次工具结果续接。其他供应商凭据保持不变。

## 其他功能

本版继续包含 Responses、JSONL 与 SQLite 联合存储、上下文用量与工具优先整理、`exec_command` / `write_stdin`、`apply_patch`、技能发现和安装、按需工具声明、电脑操作、GLM 5.4，以及 4.0.1 的登录、播放器和远控修复。

桌面、Android、iOS 源码版本统一为 4.0.2（Android 287 / iOS 236）。本次 GitHub 附件为 Windows ZIP/Setup 与 macOS arm64 DMG/ZIP；移动端版本号更新不代表同时分发移动安装包。

## 使用与验证边界

退出当前桌面程序后使用对应平台的 4.0.2。使用旧 SQLite 存储的账户会看到空的新 Agent 会话列表；账号、IM、云盘仍保持。已有新版 JSONL 记录继续保留，不自动删旧文件。

OpenAI 后台已经完成配置；重新打开应用后，在创作中心选择 GPT-6.1 Sol 即可。没有新增模型代理，模型与媒体字节仍由客户端直接发送给供应商。

会话改动已有正常 Windows 12 套 Core/Qt、控制台端到端、实际候选隔离启动与 Android arm64 JNI 编译验证；本次正式包由相同冻结源码分别构建，源码、产物摘要与包内验证以各平台 manifest 和 SHA256SUMS 为准。

Windows 应用和安装程序未签名，Setup 只做静态解包验证而不在测试机安装。macOS 使用 ad-hoc 签名、未做 Apple 公证，按最低 macOS 14.4 构建并检查依赖；未将构建检查宣称为旧系统或 Intel 实机运行验收。

完整真实账号登录 UI、跨设备远控进房、长上下文缓存命中、移动端无公网 Wi-Fi/蜂窝完整矩阵仍保留既有验证边界；本轮不宣称 iOS 实机验收。
