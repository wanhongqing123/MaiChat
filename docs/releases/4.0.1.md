# MaiChat 4.0.1

2026-11-27 · Windows x64 / macOS arm64

本版汇总近期的会话存储、上下文用量、命令工具、技能安装和电脑操作改进，并保留 3.2.2 的扫码登录修复。桌面、Android 和 iOS 的产品版本统一为 4.0.1；本次桌面发布不代表同时分发移动安装包。

## 会话与上下文

- 会话原文改用追加式 JSONL 保存，SQLite 保存索引和原文引用。旧数据库只读迁移并保留原件；启动准备提供进度与取消，源数据异常会明确报错。
- 上下文整理优先逐步压缩工具输入、输出和执行日志，以每轮约回收 20% 为目标，保留用户与助手交流正文。原始记录、压缩窗口和引用表可回查；无法满足硬限时明确停止，不为凑比例删正文。
- 本地与远端会话显示最近主请求的实际 token 用量，区分输入、输出、缓存、思考及数据来源；当前窗口占用、单轮消耗和会话累计分别计算，摘要消耗不覆盖主请求占用。
- 修正首轮估算误差持续放大后续上下文的问题，使用实测前缀加新增内容估算，并跨轮次、重开恢复。已发送的工具结果和技能内容保持稳定；加密 reasoning 续接按原始结构保留。
- 主聊天统一使用 Responses，移除 Chat Completions 旧路径。完成的原生输出项与未知字段可恢复，尚未完成的流式草稿只作内存展示。

## 命令、文件与技能

- 命令工具统一为 `exec_command` / `write_stdin`，支持数字会话 ID、可续接命令、可选 PTY、取消和有界输出；完整工具原文可补读。
- 修复 Windows 启动命令退出时误杀 Playwright 等后台服务的问题。后台进程仍受原会话所有权、取消、期限和资源清理约束。
- 文本修改统一使用 `apply_patch`，支持上下文定位、追加、EOF 和原换行处理；失败时明确说明已应用的部分。
- 桌面文件读取和搜索通过终端完成；移动端使用共享 C++ 文件核心上的进程内命令，补齐查找、状态、目录删除、正则搜索、编码读取和跨调用续页。移动端不启动系统 Shell/PTY，外部相册与文档原件不开放删除入口。
- 自动发现用户和项目的 `.agents/skills`，按需读取正文。支持从公开 GitHub 链接及 README 指向安装技能，固定源提交、拒绝覆盖；同会话下一条输入即可发现新技能。
- PC 新会话先提供精简工具目录，再通过 `tool_search` 选择其余工具，选中的声明在下一次模型请求生效。

## 电脑操作与界面

- `computer` 提供 Sky window2 的 13 个方法，覆盖应用与窗口发现、启动、窗口截图/原生控件观察、点击、键盘、输入、滚动、赋值、拖动、次级动作与激活。
- 按需返回窗口图片或文本，使用当前观察的窗口身份、元素索引和截图标识。高级显示器、按住输入、触摸与笔操作保留在 `computer_input`，复用同一核心。
- 删除 `desktop_browser`、隔离 Chrome/Edge 自动化及其专用 CDP 层。网页检索、抓取和普通链接打开保留；需要浏览器自动化时可使用已安装的技能与命令。
- 改进创作中心会话侧栏滚动条、本地与远端工具详情及用量展示，保留图片卡片、原文分页和旧工具历史的分类。
- 包含 Windows 扫码批准后主窗口不显示的修复，以及 MSVC/Ninja 间接头文件依赖回归。
- 修复登录头像被稀疏资料通知清空、旧查询覆盖新头像的问题，昵称和头像按各自修订独立合并，显式清空仍生效。
- macOS 视频首次打开按可用屏幕宽高各约 2/3 的边界等比适配并居中；拖动进度立即显示时间，按住时有界预览，松手定位，悬停可查看时间。普通播放器可出现在宿主全屏 Space 中，显式全屏退出后恢复正确窗口策略，保留用户手动调整尺寸。
- 远程桌面增加 IM v2 设备发现与目标电脑选择，支持对方或同账号电脑，邀请、接受、拒绝和停止均绑定选中端点，保留有人值守、无人值守、密码与控制授权限制。媒体身份使用独立设备凭据；**配套后台凭据接口尚未部署，新链路不能据此宣称已经可用**。

## 模型与 Android 同步改进

- 旗舰 `glm-5.3` 直接升级为支持图像的 `glm-5.4`，保留独立的 `glm-5.3-flash`。旧会话只更新型号元数据，历史原文保留；旧用量和旧续接不会冒用于新型号。
- 增加 GPT-6.1 Sol、图像输入及五档思考强度的客户端支持，沿用账号下发凭据、客户端直连供应商的方式。**OpenAI 后台 Key 部署仍未完成，账号可用性取决于后台配置**；不会将其他供应商 Key 用作替代。
- Android 创作中心增加实际用量条和可点击明细；未知窗口不显示虚构百分比。
- Android 增加逐请求网络选路：默认网络无公网时，在系统已有可用蜂窝及策略允许的条件下选择替代网络，DNS 与连接使用同一路由。保留 VPN、代理与数据策略，不自动重投已被受理的模型请求。
- 修复 Android 云盘根目录的 JSON `null` 被当成字符串，导致上传后根文件与文件夹不可见的问题。

## 升级前请注意

1. 完全退出旧版后，备份账户 Agent 数据目录，再首次启动新版。新存储以 `Agent/Accounts/<账户哈希>/sessions/` 为权威原文；**备份必须包含整个 `sessions/`，尤其是 `.journal/`，不能只复制 `agent.db`**。保留迁移前旧数据库及其 sidecar，以便独立回退；不要让旧版和新版同时写同一账户目录。
2. 自定义提示或脚本请将 `shell` / `shell_input` 改为 `exec_command` / `write_stdin`；旧 `desktop_process_*`、独立 `file_*` 和 `desktop_browser` 不再作为当前桌面模型入口。电脑操作使用 `computer` 的 `{method,parameters}`；旧记录仍可查看。
3. macOS 包使用 ad-hoc 签名，未做 Developer ID 签名和 Apple 公证。版本、平台、产物摘要及最终包验证以本次 Release 附件和交付记录为准。

## 已知验证边界

Windows 已有正常应用、核心、定点 Qt、隔离打包启动和自有 Playwright 网页任务的验证记录。GPT-6.1 Sol 的真实 C++ 客户端完成过两次有界请求与一次工具续接，不能据此保证长上下文缓存命中或后台已上线。

Android 4.0.1(286) 已完成正常 App 的 Shell/补丁/技能/用量、实际 IM 双向和云盘上传下载删除闭环；语音录音与 ASR 链路已走通，未做识别准确率验收。无公网 Wi-Fi 到蜂窝及 VPN、省流量、IPv6 等完整组合尚未实测。iOS 4.0.1(235) 的本轮改动不宣称已完成模拟器或真机运行验收。

macOS 窗口截图与原生坐标映射仍未校准，返回标记保持 false，并拒绝由图片推导的坐标输入；提供者支持的原生元素操作仍可用。本版电脑操作由当前主模型决策，没有增加独立 GUI 决策模型。模型和媒体请求仍由客户端直连供应商，服务端只承担账号、配置和凭据控制面职责。

Mac 本地版本已有头像定点回归和播放器 R4 操作验收；该结果来自合并前 Mac 本地构建，最终 4.0.1 分发包仍需按同一发布源码重新构建核验。完整模型对话和真实云盘双击播放未单独验收；新远程协议已有自有控制器、实际选择器和 Swift 编解码验证，未完成真实 iPhone/Windows 跨设备闭环。

完整功能与证据对应关系见[功能覆盖核对](../diagnostics/2026-11-27-release-4.0.1-feature-coverage.md)。
