# GPT-6.1 Sol Responses 接入

**Goal:** 将 gpt-6.1-sol 加入既有主聊天模型目录，使用后台受限环境配置中的 OpenAI Key，经既有账号凭据接口下发后由客户端直连 OpenAI Responses API。

**Architecture:** 复用单一 Responses 客户端、共享 Core 能力目录和按供应商取凭据回调。后台仅保管/下发凭据，不转发模型请求或输出。用户已明确沿用其他供应商的获准账号授权范围，不增加个人 Key 入口或替代凭据路径。

**Reference:** https://developers.openai.com/api/docs/models/gpt-6.1-sol；1050000 输入/输出共享上下文窗口、128000 输出上限；图像输入、五档推理、工具使用 Responses。Codex 默认窗口与 API 窗口不同，不把同名型号当成相同会话环境。
