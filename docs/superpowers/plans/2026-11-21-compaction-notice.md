# 对话区上下文压缩提示

用户要求压缩时出现类似 Codex 的提示；沿用已实现的真实 ContextStatus，不另建任务或猜测进度。

- 在桌面对话区底部、输入框上方使用一个常驻创建的提示控件，开始实际 Summarizing 时显示“正在压缩上下文…”。不弹阻塞窗口、不抢焦点、不重建消息页面。
- 正常完成就地改为“上下文已压缩，原始记录仍可回查”，4 秒后收起。失败、中断、延后或仅来源索引均给准确文案，不冒称压缩成功。
- Preparing、普通请求、历史重放或复用检查点不产生新的压缩通知。冷切回活动压缩可以恢复提示，切到其他会话立即隐藏；新轮次撤销旧通知和旧计时。
- 提示是宿主展示，不写入用户历史或模型请求。timer 与控件同寿命，更新/切会话停止旧 timer，防止关闭下一次的活动提示。
- 先在现有生产组件夹具增加缺失提示的 RED，再验证开始/终态、会话隔离、完成收起、后续复用不重复；正常 App 构建和 PE 门禁、组件截图人工检查。其他平台未接入不冒称完成。
