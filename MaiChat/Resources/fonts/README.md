# Shared code font

`SarasaFixedSC-Regular.ttf` is the unmodified Regular face from the official
[Sarasa Gothic v1.0.43 release](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.43).
The original copyright notice and SIL OFL 1.1 are in `LICENSE-SarasaFixedSC.txt`.
Keep both files in each product package.

- File: 13,758,860 bytes.
- SHA-256: `c261cee9121cc537fb3bb6d35c113019bf1f5601ee130b5d9521948a71f9459a`.
- Family: `Sarasa Fixed SC`.
- PostScript name: `Sarasa-Fixed-SC-Regular`.
- The original Fixed face has no programming ligatures.
- Verified ASCII and box-drawing advances are 0.5em; basic CJK advances are 1em.

Qt embeds this file through its qrc, Android includes this shared directory as
assets, and iOS references the same file in its App Resources phase and UIAppFonts.
Body typography remains separate. Do not substitute a platform's generic
monospace face or silently modify source whitespace to correct an invalid diagram.
