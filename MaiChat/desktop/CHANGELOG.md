# 更新记录

## [2.2.64] - 2026-11-15

### 修复

- 好友绑定 Session 的消息受理后，立即显示与本地输入相同的等待状态及停止按钮，不再等待模型首段输出；保留未发送草稿和原消息转发流程。
- Mac 视频首次显示时同步原生视口与 Metal 呈现层尺寸，并关闭默认弹出缩放，修正窗口已到位但画面仍局限在旧尺寸的情况。
- 各桌面端普通视频窗口默认上限统一为 960×540 逻辑尺寸，小屏按可用区域再缩小，同时保留最小操作尺寸及用户明确的最大化、全屏意图。

### 验证边界

- 绑定入口使用实际 Core/面板和自有 IM、模型替身验证首输出前状态；未以此冒称完整两账号联网验收。
- Mac 首次显示的图层几何及既有绘制用例已回归；不把图层采样当作连续窗口合成录屏。

## [2.2.63] - 2026-11-15

### 修复

- 好友绑定 Session 后，持续转发中间回复正文、可见图片与最终回复，并在本机聊天记录保留一份；本地发起的任务同样适用，工具调用不转成聊天正文。
- 本地发送、修改模型或思考强度不再静默中断绑定输出；处理停止、换绑、清空及迟到回调时保持准确归属和消息次序。
- 创作中心不再把导入历史的内部安全封装与 JSON 当作消息正文；旧自动标题按来源只读修正，保留原消息及人工标题。
- 摘要超预算采用有限重试和数据库原史回查，避免可恢复的上下文整理失败直接中断任务。
- Mac 视频控制栏跟随播放器进入原生全屏 Space，避免图标消失和创作中心出现独立浮层。
- 视频先准备实际尺寸再首次显示，图片展开/缩回全程使用同一窗口，修正开合交接；Mac 全屏关闭前撤去可见像素并保留正常退出生命周期。

### 验证边界

- 原生拖拽在当前 Windows 150% 缩放配置实测落点与轨迹偏差为 0；本次没有凭验证失败修改坐标算法。
- 源码回归、正式产物及公开发布结果分别记录；不以替身测试冒称两个真实账号或用户现装版本已验收。

## [2.2.62] - 2026-11-15

### 新增

- AI 可通过 `agent_send_file` 将工作区中的现有文件交付为当前对话的持久文件卡片，点击预览或另存为。
- 好友发送工具 `maichat_send_media` 支持 `type=file`，复用普通附件发送。
- 绑定会话接入中间正文、执行活动、问答及明确审批交互。
- 远端会话可按用户点击重新准备单张旧图片，复用有效缓存并校验所属设备与消息身份。

### 修复

- 自动回复不再默认引用用户原消息；忙碌时追加的消息进入原会话，并保持顺序。
- 停止、切换工作区、账号或绑定后，拒绝旧消息与旧审批继续执行。
- 登录后才创建的桌面窗口正确加载头像；已接受但尚未同步为 SDK 好友的联系人可独立刷新资料。
- 透明 PNG 预览使用浅色衬底，避免透明留白显示成黑边。
- 文件卡片切换会话、目录变更、异常元数据和取消准备时的生命周期处理。
- Mac 视频关闭时立即隐藏原生窗口并保留完整退出生命周期，支持连续全屏关闭与重开。
- 修正视频浮层的原生独立缩放和悬停文字提示，保持窗口边缘缩放、标题栏与控制键一致。

### 调整

- 暂停万相视频及五个付费图像入口的新任务和付费修订，保留已有任务的受支持回收操作及本地免费图像处理。

### 验证边界

- 此记录对应候选版本；公开发布与安装运行结果单独记录。
- Mac 播放器的全屏/窗口层级后续修复仍在独立验收，不计入本条已修复清单。
