## [4.0.2] - 2026-11-28

桌面、Android、iOS 产品版本统一为 **4.0.2**（Android 287 / iOS 236）；本次桌面发布说明见 [4.0.2](../../docs/releases/4.0.2.md)。

### 改进

- Agent session 首次使用新版时从空记录开始，常规启动不导入旧 SQLite 历史；旧库及 sidecar 原地保留，账号、IM 与云盘不重置。
- 桌面、移动端与控制台共用当前格式启动入口；新索引使用 `.v16` 后缀，定时任务跟随新索引，不继续旧会话的任务。已有有效新版 JSONL 与新记录的重开、索引重建继续支持。
- 产品工厂始终禁止旧库迁移，选定的新存储损坏或格式不支持时明确失败，不用另一份空库掩盖错误。路径选择只查文件，保持既有 SQLite 连接开销。
- GPT-6.1 Sol 后台凭据配置已完成部署，实际凭据接口与账号解析模块验证通过；客户端沿用账号下发 Key 与直连供应商，保留图像输入、五档思考强度和工具续接。
- 包含 4.0.1 的全部既有功能；独立发布新安装包，保留 4.0.1 的 tag 和附件。

### 验证范围

- 会话改动在正常 Windows 构建通过 12 套 Core/Qt、控制台端到端和实际 staging 隔离启动，Android arm64 正常 JNI 目标编译通过。4.0.2 正式分发包另按冻结提交核验，其结果以对应发布清单为准。
- 主模型真实调用与工具续接已有有界验证，不据此保证长上下文缓存命中。iOS 本轮不宣称实机验收；macOS ad-hoc 未公证，旧系统与 Intel 运行边界保持。

## [4.0.1] - 2026-11-27

桌面、Android、iOS 产品版本统一为 **4.0.1**。本次发布说明及迁移须知见 [4.0.1](../../docs/releases/4.0.1.md)。

### 新增与改进

- 主聊天统一为 Responses，移除 Chat Completions 旧实现及构建路径；原生完成项、未知字段和加密 reasoning 续接保持原始结构，未完成新草稿只作内存展示。
- 增加 GPT-6.1 Sol 客户端路由、图像输入与五档思考强度，复用账号凭据下发与客户端直连；后台配置于 11 月 27 日 19:28 完成部署，真实凭据接口与实际账号解析模块验证通过，已有 4.0.1 无需重装。
- GLM 旗舰型号由 glm-5.3 替换为支持图像的 glm-5.4，保留独立的 glm-5.3-flash；旧会话只升级型号元数据，历史原文保留，旧计量和续接不冒用。
- Android 创作中心接入服务端 token 用量与上下文明细；未知窗口不伪造百分比，当前占用与累计消耗分开显示。
- Android 新增逐请求网络选路：默认网络无公网时可使用系统允许的已可用蜂窝，DNS 与连接保持同一路由；保留 VPN、代理和数据策略，换网不自动重投已受理的模型请求。
- 桌面与移动端均不再向模型注册独立 file_*：桌面走系统终端，移动端走共享文件核心上的进程内命令，精确修改统一用 apply_patch。补齐 find/stat/rmdir/read-text 与正则 grep、编码和跨调用续页，不创建移动系统 Shell/PTY。相册与文档原件不开放删除入口。

- 支持从公开 GitHub 链接发现并安装技能：识别真正的 SKILL.md 目录及 README 指向，固定源提交并无覆盖安装到标准目录；同会话下一条输入可发现，未变化的目录元数据不重复发送。
- 电脑操作提供 Sky window2 的 13 个方法：应用发现/启动、窗口状态、焦点与选择/正文事实、逻辑坐标输入、原生元素赋值及次级动作；保留共享核心的高级 `computer_input` 扩展，旧工具快照显式升级并保留原文。
- PC 新会话启用精简工具声明与按需发现，Shell/Skills 和必要补读能力先提供，其余选择后在下一请求追加；旧会话前缀保持稳定。
- 本地与远端会话显示最近主请求的实际 token 用量和可信窗口，区分缓存、推导、缺失及累计；压缩消耗单独累计，不覆盖主窗口占用。
- Skills 目录按窗口预算缩短描述和分页发现，支持显式调用策略，未选正文不预先加载。
- 会话正式改为追加 JSONL 原文与 SQLite 索引：只读迁移旧库并保留备份，索引可重建；启动准备在后台显示可取消进度，完成 item 与未完成草稿分开处理。
- 上下文整理先逐步缩减工具详情，目标为每次约回收当前输入 20%，保留用户及助手交流正文；正文保护优先于比例，超出硬限而无法安全缩减时明确停止，压缩窗口及引用表可回查。
- 接入标准 `.agents/skills` 技能目录、按需正文读取和显式技能选择；同一输入的技能快照跨工具跟进、重启保持稳定。
- 命令工具按 Codex 0.172.0 对齐为 `exec_command` / `write_stdin`：数字会话 ID、可续接生命周期、显式 PTY 交互与统一输出；旧 `shell` / `shell_input` 和 `desktop_process_*` 仅用于历史记录分类。
- 存储工具默认返回汇总，候选明细显式分页；增加压缩存档与完整引用表的只读查询，以及统一工具结果预览/原文补读能力。
- 合并本地已有的轮次终态、子任务报告隔离、原始用户要求保护和上下文状态显示；保留公开 3.2.0 的跨设备图片、等待状态及 HTTP 413 恢复。
- 创作中心侧栏使用统一无箭头细滚动条，本地与远端工具详情保留命令原生字段、输入输出分页和内置/Shell 分类；保留图片卡片去重、历史恢复与预览行为。
- macOS 播放器首次按可用屏幕宽高各约 2/3 等比适配并居中，进度拖动即时显示时间、按住时有界预览、松手定位，悬停显示时间；普通播放与显式原生全屏切换后恢复对应 Space 策略及用户尺寸。
- 远程桌面增加 IM v2 设备发现和目标电脑选择，所有会话信令绑定选中端点，支持对方与同账号电脑；设备媒体身份改由独立鉴权凭据下发，保留值守、密码和控制守卫。配套后台接口已部署；完整真实跨设备进房仍未验收。

- 清理上下文等待状态在外层标题中的重复前缀，百分比、计量来源及窗口计算保持不变。
- 包含 3.2.2 的 Windows 扫码批准后主窗口不显示修复，以及 MSVC/Ninja 中间接头文件依赖和实际主窗口创建回归。
- 登录资料按昵称和头像各自修订合并，避免稀疏通知丢头像或旧查询覆盖新头像/显式清空。
- macOS 独立命令宿主以文件描述符抑制 SIGPIPE，修正系统 signal 宏的调用方式；保留现有命令/PTY/Job 生命周期，不修改全局 signal handler。
- 修复 Android 将云盘根目录的 JSON null 当字符串处理、导致根文件及文件夹上传后不可见的问题。
- 修复 Windows Shell 启动命令结束时误杀 Playwright 等后台服务的问题，管道/ConPTY 保留原 Job 所有权、额度和取消/期限/所有者清理，支持技能跨命令持续操作浏览器。
- 电脑操作工具正式名改为 `computer`，旧工具快照显式升级并保留原文；修正窗口不能返回图片的旧提示，按需直接获取目标窗口图片或控件信息，无需先调独立截图工具。
- 基础补丁统一为 `apply_patch`，对齐 Codex 的上下文定位、追加、EOF、逐行换行和顺序执行；OpenAI 原生自由文本调用完整回传，失败明确列出部分已应用结果。
- Windows PowerShell 运行中输出改用上游 UTF-8 前缀；文件搜索保留独立 CR、计入 ignore 输入预算，并拒绝相反 UTF-16 BOM，避免乱码或误报无匹配。
- 修复整份上下文被首轮误差倍率持续放大的问题，改用可验证的实测前缀与新增尾部估计，并支持跨轮次、重启恢复。
- 续接估算不再把签名、ID、JSON 包装当正文；保留真实加密续接内容和必要的思考估算。摘要 413 不能绕过 token 硬限。
- 已发送工具结果的完整模型表示按来源及型号固定并跨 SQLite 重开保存；动态预算只分配新结果，避免未推进压缩检查点时改写旧请求前缀。旧记录不追溯截短。
- 原始用户要求展示预算随检查点保存，追加尾部不会重新裁剪同一检查点；合并截图运行态诊断及浏览器遮挡观察修复。

### 升级

- 退出旧版后直接启动新版，程序自动导入已有会话，完成后日常只用新版存储，无需手动转换数据库；迁移前原件由程序保留。若另做备份，复制整个账户 Agent 目录，包含 `sessions/` 及 `.journal/`；仅复制 `agent.db` 不含权威原文，新旧版不得同时写同一账户目录。

### 验证边界

- 发布包和平台边界以本版 Release 实际验包记录为准；不替换用户现装，不承诺每次恰好20%或真实费用节省。
