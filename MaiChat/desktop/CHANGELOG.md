# 更新记录

## [Unreleased]

### 新增与改进

- 合并长期积压的文件操作、搜索统计、curl 请求能力、Shell 持续会话及解释器环境适配；正式进程入口统一为 `shell` / `shell_input`，旧 `desktop_process_*` 仅用于历史记录分类。
- 存储工具默认返回汇总，候选明细显式分页；增加压缩存档与完整引用表的只读查询，以及统一工具结果预览/原文补读能力。
- 合并本地已有的轮次终态、子任务报告隔离、原始用户要求保护和上下文状态显示；保留公开 3.2.0 的跨设备图片、等待状态及 HTTP 413 恢复。

### 修复

- 已发送工具结果的完整模型表示按来源及型号固定并跨 SQLite 重开保存；动态预算只分配新结果，避免未推进压缩检查点时改写旧请求前缀。旧记录不追溯截短。
- 原始用户要求展示预算随检查点保存，追加尾部不会重新裁剪同一检查点；合并截图运行态诊断及浏览器遮挡观察修复。

### 验证边界

- 本次提交只更新源码，未修改或重新发布 3.2.0 安装包。Windows 正常应用构建、核心及定点界面回归已执行；Mac/Linux 原生运行和移动端界面未在本轮实机验证。

- 本版发布 Windows Setup/ZIP 及校验元数据；不修改用户数据，不自动替换现装，不构建 macOS 或移动端。

## [3.2.0] - 2026-11-23

### 修复

- 跨设备输入队列首次启动及上一轮结束后的接续轮次，在持久化成功、worker放行前发出开始通知，恢复等待状态与停止按钮；排队和重入语义保持。
- 远程会话输入框实际接收原始图片MIME与本地文件拖放，复用既有附件校验、发送队列和持久草稿；仅图片也可发送，清除附件后不会在重开面板时复现。
- HTTP 413 请求体超限与 token 窗口超限分别处理：按实际编码 JSON 字节整理历史上下文，最多四次严格缩小后重试；摘要及格式重试也按字节有界分块。保留原始历史与当前受保护输入，不重跑工具、不降低输出 token 上限；无法安全缩减时明确停止并提示新会话或缩小当前图片。

### 验证边界

- 定点Core队列、远程等待UI和自有Cocoa MIME五场景验证随本版记录；不修改系统剪贴板，不把替身测试冒作真实模型/跨设备联网验收。
- 本版聚合两项跨设备修复及 HTTP 413 请求体恢复；413 普通 Core 定点覆盖两协议回环计量、旧图恢复、当前四图保护、不可缩输入停止和摘要重新分块，不使用真实模型请求。
- 不含其他Root WIP；旧Release与现装不覆盖。
- 同一 `v3.2.0` 已公开 Windows x64 Setup/ZIP、macOS arm64 DMG/ZIP 与两端 manifest/SHA256SUMS；八件摘要与四 metadata 下载原字节核等，平台和定点验收边界见本版交付记录。

## [3.1.3] - 2026-11-23

### 调整与修复

- 工具组显示内置与 Shell 各自的调用次数，保留混合状态、展开/折叠和分组计数隔离。`ssh_exec`、`curl`、`openssl` 归内置；`shell`、`shell_input` 及原有四个 `desktop_process_*` 归 Shell，不退役已有工具。
- 未压缩的用户与工具图片不再按8张/12引用滑窗省略；附件标签和已发送前缀保持稳定。原生无供应商续接载体的连续响应单独保存非显示边界，防止后续调用并入旧 `tool_calls`。
- 压缩优先逐字段整理旧工具详情，按触发前完整输入每轮约回收20%；仍需满足输入硬限，整张图片等不可分单位可能导致更多回收。工具到必要骨架后才选择部分旧正文摘要，未选字段保留，原始历史与精确回查保持。
- OCR 过宽行可在有独立背景证据时有界切分，保留其他可识别标签和原图坐标；无法安全恢复的行通过 `partial`、`skipped_lines` 明示，不再直接让整图失败。模型和字典不变。

### 验证边界

- 自有本地/远程分类 GUI、图片完整字段前缀、memory/SQLite 重开和工具优先压缩选择器已验证；不是完整实机工具或真实供应商缓存命中验收。
- 仅包含三功能19件与 OCR7件；不包含私有截图运行态诊断、其他未聚合的上下文接口或 UI 状态改动。
- 发布包和平台边界以本版 Release 实际验包记录为准；不替换用户现装，不承诺每次恰好20%或真实费用节省。
- 同一 `v3.1.3` 已公开提供Windows x64 Setup/ZIP、macOS arm64 DMG/ZIP及两端manifest/SHA256清单；八件摘要与四metadata下载原bytes核等，三copy隔离启动及本版OCR过。Mac ad-hoc未公证，实际27.2 arm64，旧系统/Intel未实机。

## [3.1.1] - 2026-11-21

## [3.1.0] - 2026-11-20

### 新增

- 桌面操作可保留整屏截图坐标，同时将鼠标、键盘、文字与批量输入限定到观察到的窗口；越界、接收窗口变化或失焦时明确拒绝，释放操作仍可完成清理。
- 本地 `ocr_image` 与普通 OCR API 共用检测、识别和原图坐标实现，支持文字、置信度和四边形结果；模型内置并复用现有 ONNX Runtime，无远程 OCR 请求。
- Windows 窗口观察可返回同源截图和实际图像尺寸，保留原生控件 ID、最小化/恢复入口及明确的坐标参考空间。
- 新增 Particle-1 免费主模型和 OpenRouter Claude Fable 5.2，Fable 支持五档思考强度；新增“小”字号选项。

### 调整与修复

- 云端主模型统一使用 Responses 协议，接通会话身份与供应商缓存参数；通用网页检索与主模型供应商解耦。
- 上下文压缩按实际输入窗口和明确预留预算触发，保留原始历史回查能力。
- 发送方图片可点击放大并在历史中重新打开；修正已知 HTTP 402 被中途断流覆盖为网络错误的情况。
- 修正自动观察续接误接被复用窗口、撤销后恢复旧快照及笔/触摸持续报告遗漏接收窗口校验的边界。

### 验证边界

- 初次公开提供 Windows x64，随后已在同一 `v3.1.0` 发布补齐同源 macOS arm64 DMG、ZIP 和校验文件。Windows 正常构建、相关回归、本地 OCR、150% 缩放下自有窗口截图映射及发布包启动均有验证；前台点击/输入正向验收仍未完成。
- Mac 以固定发布源码完成正常配置、构建与打包，签后 staging、ZIP 和只读 DMG 三副本的内容、签名、依赖、隔离启动及包内 OCR 已验证。签名为 ad-hoc，未公证；14.4 是构建目标及静态门禁，实际执行平台为 macOS 27.2 arm64，未做旧系统或 Intel Mac 验收。
- OCR 文字框不等于可点击控件，不承诺任意小字完全准确。Mac 窗口图片到原生坐标的映射明确标为未校准，视觉定位使用整屏截图加窗口约束或原生 AX 元素。
- Particle 免费端点受供应商限额约束，其他工具费用保持各自原有规则；不自动切换到付费同名模型。
